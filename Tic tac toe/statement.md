# 5.2 Statement — Tic Tac Toe Game

## Problem Statement

Tic Tac Toe is a simple two-player game, but developing it in Python requires applying programming concepts such as lists, functions, conditional statements, loops, Boolean conditions, input validation, and algorithmic decision making. This project implements a functional command-line Tic Tac Toe game to demonstrate these CSE1021 programming and problem-solving concepts.

## Scope of the Project

The project covers a 3×3 two-player Tic Tac Toe game. Players take turns placing X and O on the board. The system accepts player input, validates moves, updates the board, checks winning combinations, detects a draw, and displays the final result. The project is implemented using Python and focuses on concepts suitable for a first-year CSE1021 project.

## Target Users

- First-year engineering students
- CSE1021 learners
- Faculty evaluators
- Students learning Python programming and basic algorithms

## High-Level Features

- 3×3 Tic Tac Toe board
- Two-player gameplay
- Position-based player input
- Move validation
- Automatic turn switching
- Winning-pattern detection
- Draw detection
- Winner/result display
- List-based board representation
- Functions and conditional logic
- Loop-based game control
- Basic algorithm demonstrations
