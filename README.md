## 1. Quiz App

The Quiz App is a simple Python-based quiz application. The user gets a set of questions and selects an answer for each question. At the end, the application calculates the score and shows the result.

### Main Features

1. Multiple-choice questions
2. Question bank
3. Randomized questions
4. Randomized answer options
5. Score calculation
6. Correct and incorrect answer tracking
7. Final result
8. Input validation

### Python Concepts Used

1. Variables
2. `if`, `elif` and `else`
3. `for` and `while` loops
4. Functions
5. Lists
6. Dictionaries
7. Tuples
8. Sets
9. Random module
10. Input validation
11. Basic error handling

### How It Works

The program starts by loading the questions. Questions can be presented in a random order so that the quiz is not exactly the same every time.

The user selects an option for each question. The program checks the answer and updates the score. After all questions are completed, the final score and performance are displayed.

### Run the Project

Open a terminal inside the Quiz App folder and run:

```bash
python main.py
```

If the entry file in the folder has a different name, run that Python file instead.

# 2. Tic Tac Toe

Tic Tac Toe is a two-player game made using Python. The game uses a 3x3 board and two players take turns placing their symbols.

One player uses `X` and the other uses `O`.

### Main Features

3x3 game board
Two-player mode
Turn-by-turn gameplay
Input validation
Win checking
Draw checking
Restart/new game option

### Python Concepts Used

1. Functions
2. Lists
3. Loops
4. Conditional statements
5. User input
6. Game logic
7. Input validation
8. Basic algorithms

### How It Works

The program first creates an empty 3x3 board. Players take turns choosing an available position.

After every move, the program checks the rows, columns and diagonals to see if a player has won.

If all positions are filled and nobody wins, the game ends as a draw.

### Run the Project

Open a terminal inside the Tic Tac Toe folder and run:

```bash
python main.py
```

# 3. College Event Management System

The College Event Management System is a Python application for managing basic college event information and student registrations.

The idea behind this project is to make it easier to keep track of events and the students participating in them.

### Main Features

Add and manage events
View available events
Student registration
Participant management
Registration validation
Event information
Attendance/participant tracking

### Python Concepts Used

Functions
Lists
Dictionaries
Loops
Conditional statements
Input validation
Data handling
Modular programming

### How It Works

The application stores information about college events and their participants. Users can view events and register students for suitable events.

The program checks the entered information before accepting it so that incorrect or duplicate entries can be handled properly.

### Run the Project

Open a terminal inside the College Event Management folder and run:

```bash
python main.py
```

# How to Run the Projects

## 1. Install Python

First, make sure Python 3 is installed.

Check it using:

```bash
python --version
```

If that does not work on Windows, try:

```bash
py --version
```

## 2. Clone the Repository

Clone the repository using:

```bash
git clone https://github.com/adi-259/Vityarthi_Project.git
```

Then move into the repository:

```bash
cd Vityarthi_Project
```

## 3. Open the Project You Want to Run

For example:

```bash
cd "Quiz App"
```

Then run:

```bash
python main.py
```

For Tic Tac Toe:

```bash
cd "Tic tac toe"
```
Then run:

```bash
python main.py
```

For College Event Management:

```bash
cd "College Event Management"
```
Then run:

```bash
python main.py
```

The exact command may need to be changed if the project's main Python file has a different filename.
