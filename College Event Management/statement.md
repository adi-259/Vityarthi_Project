## College Event Management

## Problem Statement
Managing college events and student registrations manually can make it difficult to organize event details, track participants and view registration statistics. This project provides a simple Python-based system for storing events, registering students and generating basic event reports.

## Scope of the Project
The project covers event creation, event information storage, student registration, duplicate-registration prevention, event display and basic reports such as total registrations and maximum registrations. It uses Python lists, dictionaries, functions and control-flow concepts. The project is limited to a only Python implementation without external packages.

## Target Users
College students, student event coordinators, faculty or club coordinators.

## High-Level Features
- Create and store college events
- Generate event IDs
- Store event name and venue
- Register students for events
- Prevent duplicate registrations
- Display available events and registration counts
- Calculate total registrations
- Find maximum registrations
- Separate Python modules for event, registration and algorithm functionality
